# Kyiv Favourite Places

Django-застосунок для лабораторної роботи: особистий каталог улюблених місць
у Києві (ресторани, кав'ярні, парки, розваги тощо). Кожен зареєстрований
користувач бачить лише свій власний список.

## Функціонал

- **Головна сторінка** — назва сайту, короткий опис і кнопка
  «Куди піти сьогодні?». Вона обирає випадкове місце з вашого списку —
  місця з вищим рейтингом обираються з вищою імовірністю (зважений
  випадковий вибір). Результат виводиться після перезавантаження сторінки.
- **Список місць** — картки з назвою, початком опису, типом місця,
  локацією (або "Secret place👀", якщо локацію не вказано), рейтингом у
  вигляді зірочок, датою додавання і фото (наразі одне стандартне на всіх).
  Клік по назві веде на сторінку з повним описом. Картка реалізована як
  окремий шаблон (`places/includes/place_preview.html`), який
  використовується і в списку, і на головній сторінці.
- **Додавання нового місця** — форма з валідацією (назва не може бути
  порожньою, рейтинг — ціле число від 1 до 5). Після успішного збереження —
  редирект на список місць.
- **Реєстрація / вхід / вихід** — списки місць розділені між користувачами
  через стандартну автентифікацію Django (`request.user`, поле `owner` у
  моделі `Place`).

├── .venv/
│
├── kyiv_places/
│   ├── settings.py
│   ├── urls.py

│   ├── base.html

│

models.py — місця та їхні дані.

forms.py — форма додавання + валідація.
urls.py — адреси сторінок.
base.html — спільні header/footer.
home.html — головна.
places.html — список місць.
detail.html — повна інформація про місце.
form.html — додавання нового місця.
style.css — весь дизайн.

## Технології

- Django 5.x
- SQLite (стандартна БД для розробки)
- Звичайний CSS, без JavaScript та зовнішніх бібліотек
